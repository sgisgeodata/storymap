# 🗺️ 교육서비스업 공간분석 스토리맵

**🎓 우리가 아는 교육의 중심지, 통계도 같을까?**

교육의 중심지로 익숙한 서울 강남구 대치4동과 경남 양산시 물금읍을 SGIS 통계 및 공간정보로 비교하는 인터랙티브 스토리맵입니다. 교육서비스업 사업체 수에서 출발해 인구, 학령인구, 학교, 학원·교습소, 학교 도보 접근성, 세부 업종, 종사자 수를 차례로 살펴봅니다.

## 🔍 분석 방법

1. **전처리:** 지역별 인구·시설·교육서비스업 통계를 정리하고 공간자료 형식을 통일
2. **지표 산출:** 사업체 수, 종사자 수, 사업체당 종사자 수 및 주요 업종 구성비 계산
3. **공간분석:** 격자별 인구 분포, 학교·학원 위치, 학교 도보 접근성 비교
4. **결과 도출:** 01~07번 카드의 지도·그래프를 통해 지역별 특성과 해석상 한계 제시

## 📊 주요 분석 내용

| 단계 | 주제 | 확인 내용 |
| --- | --- | --- |
| **01** | 총인구 분포 | 두 지역의 거주 인구가 어디에 집중되어 있는지 비교 |
| **02** | 학령인구 분포 | 교육서비스 주요 수요층의 공간적 분포 비교 |
| **03** | 학교 위치 | 초·중·고등학교의 위치 및 배치 특성 확인 |
| **04** | 학교 도보 접근성 | 학교 기준 도보 5분·10분 생활권 비교 |
| **05** | 학원·교습소 분포 | 대치4동·물금읍과 강남구·양산시 전체의 분포 비교 |
| **06** | 교육서비스업 세부 업종 | 주요 7개 업종의 사업체 수·구성비와 전체 33개 업종 비교 |

### 🏆 주요 비교 결과

| 지표 | 물금읍 | 대치4동 |
| --- | ---: | ---: |
| 교육서비스업 사업체 수 | **974개** | 852개 |
| 교육서비스업 종사자 수* | **4,334명** | 4,023명 |
| 사업체당 평균 종사자 수* | 약 4.45명 | **약 4.72명** |

2024년 SGIS 전국사업체조사 API에서 수집한 프로젝트 JSON의 지역별 전체 집계값 기준입니다. 물금읍은 사업체 수가 122개(약 14.3%) 더 많지만, 사업체당 평균 종사자 수는 대치4동이 더 높습니다. **사업체 수의 순위가 교육환경의 우수성을 의미하지는 않습니다.**

\* 종사자 수는 세부 업종별 합계와 전체 집계값 사이에 차이가 있어 최종 검증이 필요합니다.

## 🗺️ 주요 기능

- **지도 기반 탐색:** 전국 위치 지도와 행정경계 비교 지도 제공
- **스크롤형 스토리텔링:** 01~07번 단계에 맞춰 지도 레이어 또는 비교 패널 전환
- **레이어 비교:** 총인구·학령인구 격자, 학교 위치, 학원·교습소 위치 표시
- **지도 조작:** 학원 표시 범위(동·읍 / 시·구 전체) 전환, 도보 5분·10분 생활권 ON/OFF
- **업종 시각화:** 주요 7개 업종 막대그래프·지역별 파이차트, 전체 33개 업종 상세 표
- **종사자 비교:** 사업체 수·종사자 수·사업체당 평균 종사자 수 시각화
- **반응형 화면:** 모바일에서 활성 카드 아래로 지도 패널 이동

├── data/
│   ├── education_industry_2024.json  # 2024년 교육서비스업 집계

│   ├── *_population.geojson   # 총인구 격자

위 구조는 기능별 JavaScript 분리본을 기준으로 작성했습니다. `data/`에는 이 외에도 원자료와 관련된 보조 파일이 있을 수 있습니다.

## ⚠️ 분석의 한계 및 유의사항

- **총수와 밀도는 다름:** 물금읍과 대치4동은 면적·인구·행정구역 특성이 다르므로 사업체 총수만으로 시설 밀집도나 교육환경의 질을 평가할 수 없습니다.
- **인과관계 해석 제한:** 인구, 학교, 학원, 접근성의 공간적 차이가 사업체 수 차이를 직접 발생시켰다고 단정할 수 없습니다.
- **기준시점 확인:** 교육서비스업 통계는 2024년 자료이나, 다른 공간자료는 각 원자료의 기준연도를 별도로 확인해야 합니다.
- **종사자 수 검증 필요:** 교육서비스업 전체 종사자 수와 세부 업종별 종사자 수 합계 사이에 차이가 있습니다. 원자료·집계 기준 확인 전까지 수치를 확정적으로 해석하지 않습니다.
- **구성비 해석 주의:** 06번 파이차트는 주요 7개 업종만을 분모로 계산합니다.
- **접근성 해석 주의:** 지도에 표시된 도보권은 사용한 접근성 자료의 산출 조건에 따른 범위이며, 실제 개인별 이동시간과 다를 수 있습니다.
